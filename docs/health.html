Daily coverage

Expected counts only trains scheduled to arrive that day, so a light day is usually a sparse timetable rather than a failure. Today counts a train only once its arrival window has passed.

Weekly polling load

One tracked train costs one request on each day it arrives, so this is the shape of the week against RailRadar's 50/day cap. Trains whose run days we haven't learned yet count on every day, because that is how they are polled until the first response teaches us otherwise.

Outages

Two different failures, and they need different reactions. Polls failing means the workflow ran and RailRadar refused every request in it. Scheduler silent means no run happened at all — the external cron or GitHub's queue, not the API. A window missed entirely is a journey we can never go back for, which is the column that matters. The list covers the last days; the dial reads all , because a time-of-day pattern needs every failure it can get.
